# Design scope — pages, data, actions, journeys

Derived from product-spec.md v1.7. This file fixes _what_ each screen contains. design.md decides how it looks. Anything here that the spec does not define is a gap to resolve in the spec first.

Navigation: bottom bar with **Today · History · My plan**, a profile button (top right) to Settings, and a persistent **Log meal** button on all three tabs.

## Pages

### 4. Log meal (sheet, opens from anywhere)

| Step            | Shows                                                                                                                                                                                                                                                                                                                                                                                       | Actions                                                                                                                                                                                                                                     |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Compose         | Text field (any language), photo button (hidden while the photo flag is off), Recent meals row, Today's planned slots row (a multi-option slot opens its options with the last-used one marked "Last time"; nothing is preselected), date/time summary, "Logging for [date]" banner when backdated; between 00:00 and 04:00 a first prompt "Was this for yesterday?" with Yesterday / Today | Analyze (first time per kind: AI notice sheet → Continue / Enter manually) · Pick recent · Pick planned slot → choose option · Manual entry · More details (date/time, slot picker: plan slots + "Other · in addition to your plan", notes) |
| Check your meal | Items: original name + English label, quantity, unit, prep; "Estimated"/"Assumed" tags; grouped questions ("How much of this dish did you eat?"); restriction reminder line when an item matches ("Contains walnuts, which is on your restrictions list."); "Added: …" chip for extras beyond the chosen option; totals: energy, protein, carb, fat; Sources ▸; unsaved indicator           | Edit item · Add / remove item · Choose alternative identification · Enter label values · Answer question · Save meal (disabled until an option is chosen for a multi-option slot) · Retry analysis · Switch to manual                       |

States: analyzing (15 s calm status, manual option; 45 s ends the wait and keeps the draft), analysis failed (input kept), save failed (edits kept), offline (unsynced label), backdated with unknown time ("I don't remember the time"), future time not allowed (draft kept), incomplete nutrition ("Some values are unknown" notice, save still allowed), newer edit on another device ("Reload", edits kept on screen).

## Shared components

Meal composer · Meal review · Plan slot row · Score card (+ Why this score) · Nutrition details · Completeness checkbox · Reflection card · Difference chip (portion / order / different food / cross-slot reason / added item) · Original + English name label · Import status banner · AI notice sheet · Expand/collapse (one pattern everywhere).

These names match product-spec.md section 12 and are the names to use in code.

Design must verify: Persian and Arabic names beside English labels and Western digits in every component listed above, in both themes, with bidirectional isolation so punctuation and numbers do not flip.

## Journeys

| #   | Journey                 | Path                                                                                                                                                                     |
| --- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| J1  | First run               | Sign up → About you → Add plan → AI notice → Review → Confirm → Ready → Today → Log first meal                                                                           |
| J2  | Daily planned meal      | Open app → Today (reflection) → Log this meal → choose option ("Last time" suggested, not preselected) → Check your meal → Save → row shows Matched, score updates       |
| J3  | Free-text or photo meal | Log meal → type/photo → (first time) AI notice → analyzing → Check your meal → answer questions → Save → appears in Recorded meals, linked to its slot                   |
| J4  | Extra off-plan meal     | Log meal → text → More details → slot "Other · in addition to your plan" → Save → nutrition only, no slot affected                                                       |
| J5  | Replaced meal           | Log meal → text → slot "Lunch" → Check your meal → Save → lunch row shows "Different food", neutral wording                                                              |
| J6  | Backdate                | History → day → Log meal for date → confirm time or "don't remember" → Save                                                                                              |
| J7  | Correct or delete       | Today/History → meal → Edit or Delete → day recalculates; reflection marked stale only if a fact it used changed                                                         |
| J8  | Mark day incomplete     | Today or History day → uncheck → "Based on recorded meals" → Update reflection                                                                                           |
| J9  | Finish a past day       | History → day shows "2 of 5 meals recorded" → Mark skipped on the rest → day counts in patterns                                                                          |
| J10 | Replace or correct plan | My plan → Replace or Edit → Review → Confirm ("Past days will be compared against the updated plan · N meals affected") → every day re-compares against the updated plan |
| J11 | Late-night meal         | 00:30, Log meal → "Was this for yesterday?" → Yesterday → Check your meal → Save → appears on yesterday                                                                  |
| J12 | Slow or failed import   | Add plan → 15 s → Continue to Today → banner "still preparing" → "ready to review" → Review now; or "couldn't prepare" → Try again / Set up manually                     |
| J13 | No plan yet             | Skip plan → Today limited ("Add your plan") → log meals → My plan → Add                                                                                                  |
| J14 | Account                 | Settings → export / delete / log out                                                                                                                                     |

## Out of design scope (V1)

Notifications, chat, water/exercise/weight widgets, training-day toggle, photo/PDF plan import, item-level allocation of one meal across several plan slots, subscriptions, social features, native apps.
